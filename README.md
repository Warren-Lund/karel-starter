# The Adventures of Karel
- Karel is my very first game/program that I have been able to work on in my freshman year at TCU.
- Karel has some limitations that require certain coding to work around and accomplish tasks.
- To run Karel simply press on the green button at the top, or run.ps1 on Windows and run.sh on macOS.
- In order to get around Karel's limitations, you have to think outside the box a bit, and use what Karel is capable of as means to create new methods.
  For example, Karel can only turn left, meaning that we can use multiple turn lefts to create a way for her to turn right and turn around to enhance her movement capabilities.
